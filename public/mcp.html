The MCP · shaddai-mcp v2.3.0

What it does for Claude.

A Model Context Protocol server that gives Claude seven specialist agents and their knowledge bases. It runs on your machine, needs no API key, and sends nothing to us.

$ claude mcp add shaddai -- npx -y shaddai-mcp

The five tools

list_agents

See the council

Lists the seven agents, their role and goal, and how many knowledge-base documents each one holds.

list_rag_docs

Browse an agent's library

Shows the documents inside one agent's knowledge base, so you know what it can cite.

rag_search

Search the library

Returns the ranked passages and source document for a query. Good for checking what the library says before you ask.

rag_ask

Ask a grounded question

Pulls the most relevant passages for one agent and tells Claude to answer from them, with sources.

run_agent

Hand off a task

Routes a goal to the right agent (or the one you name), loads its knowledge as passages, and returns a persona and instruction for Claude to finish the work.

The seven agents

SHADDAI

Strategy

Orchestration, launch planning and decisions. The default agent.

NEXUS

Architecture

Scalable system design and engineering tradeoffs.

ZEROX

Markets

Money, pricing and unit economics.

ORACLE

Research

Research and grounded explanation.

TURTLE

Creative

Art, design and the creative process.

QUILL

Writing

Essays, copy and writing craft.

PIKADON

Security

Privacy, online security and hardening.

What it is, and what it isn't

  • The MCP retrieves and frames knowledge. Claude, running on the customer's own account, writes the answer.
  • Current knowledge bases hold 21 source files in total. We say so rather than inflate the number.
  • It is a local package. It has no hosted service yet, so it does not meter usage. Paid usage needs the hosted gateway, which is planned, not live.
