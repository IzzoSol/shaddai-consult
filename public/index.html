How an engagement runs

  1. Discovery call

    We map your workflows, tools and goals, and say plainly where agents will and won't help.

  2. Scoped plan

    A written plan with the first build, its cost and what success looks like, before any work starts.

  3. Build and test

    We build in short, reviewed steps and test each one against real examples.

  4. Handover and review

    Your team gets the docs and training, and we review usage and results on a schedule.

Questions

Do I need an API key to install the MCP?
No. The one-line install runs with no keys and no external model calls. Claude does the synthesis.
What do I pay for on usage?
The agent runs and retrieval calls you make through SHADDAI. Rates are shown before you buy.
Are answers grounded?
Yes. Retrieval returns the source documents and scores behind each answer.
Will you work with our existing tools?
That's what discovery is for. We'll tell you what fits and what doesn't before any work is scoped.
